Редактор
- оптимизация геометрии - сейчас каждый тайл - это два треугольника, при том что если соседние тайлы с одинаковой высотой их можно объединить.
- тайл с жидкостями (вода, лава, кислота). с анимацией
- водопады для них
- вместо одной карты нужны чанки, чанк добавляется если я при редактировании выхожу за пределы текущего чанка. чанк удаляется если всего его блоки Empty. и появляется как только минимум один блок Solid
- сохранение в json
- команды отмены повтора
- другие команды в меню
- возможность скрывать стороны блока (например стены или потолок)

- декорации. то что не получается сделать блоками, можно доделать декорациями. например насыпи песка. сложный рельеф. декорации - это модели

- entity. по сути тоже декорации, но с которыми можно взаимодействовать (включая предметы, сундуки, двери, врагов)
- триггеры - для программирования логики
